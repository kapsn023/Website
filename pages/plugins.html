Nagios Plugins

Nagios Core can't actually check anything on its own. For every check, it runs a separate program called a plugin and reads the result. Nagios Plugins is the standard collection of these, so almost every Nagios install depends on it.

I am the current maintainer. Most of the code is written by people in the community, so my part is reviewing their pull requests, merging them, and putting out releases.
